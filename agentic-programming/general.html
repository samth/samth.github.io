1.4 Course Shape🔗

This will be a studio-oriented programming course. Students will write code, inspect agent transcripts, review agent-produced changes, and present both software artifacts and the process that produced them.

The course will emphasize:

  • using coding agents deliberately rather than treating them as magic;

  • reviewing, testing, debugging, and explaining generated code;

  • building useful software artifacts under realistic constraints;

  • recording process evidence, including prompts, transcripts, failures, repairs, and evaluations;

  • thinking about what programming expertise means when code generation is cheap.
