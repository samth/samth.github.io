CSCI-B 490/B629: Agentic Programming🔗

Fall 2026

This course is about programming with coding agents: how to ask them to build software, how to constrain their behavior with tests and tools, how to review their output, and how to decide when agent-produced work is trustworthy.

Important start-of-semester note: The first two scheduled class meetings, Tuesday, August 25 and Thursday, August 27, 2026, are cancelled. The first in-person class meeting will be Tuesday, September 1, 2026.

Meeting time: Tuesday and Thursday, 11:10 AM-12:25 PM, in SPEA/PV A205.

Listings: CSCI-B 490, class number 35283, and CSCI-B 629, class number 35284. The two listings meet together.

Prerequisites: Students should be comfortable programming and using development tools. The undergraduate listing is intended for advanced undergraduates; the graduate listing is intended for graduate students.
