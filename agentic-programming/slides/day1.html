The course

Programming with coding agents.

  • Ask them to build software
  • Constrain them with tests and tools
  • Review what they produce
  • Decide when to trust it

Prerequisites

Comfortable programming. Comfortable with dev tools.

B 490: advanced undergraduates. B 629: graduate students.

Shape

A studio course.

  • Write code
  • Read transcripts
  • Review agent changes
  • Present artifacts and process

Emphasis

  • Use agents deliberately, not as magic
  • Review, test, debug, explain generated code
  • Build under real constraints
  • Record prompts, failures, repairs, evaluations
  • Ask what expertise means when code is cheap

Arc

  • How agents work, and small programs
  • Evaluation — did it actually work?
  • Bigger programs, changing over time
  • Coming in cold to an existing codebase
  • Tools; then write your own minimal agent
  • Verification beyond testing
  • Remote tooling; factories of agents
  • Presentations

Full schedule on the course page.

Work

  • Process notes — paper notebook, plus commits and transcripts
  • Short builds — small testable artifacts
  • Review exercises — find defects, improve tests
  • Final project — build, evaluate, present

Weights and due dates: posted with each assignment.

Notebook

Paper. Bring it to every class.

  • Plans, sketches, questions
  • Decisions and stuck points
  • Written while working, not after

Tools

Codex, through IU's ChatGPT Edu.

  • Sign in with @iu.edu, choose Indiana University
  • Not a personal account, not an API key
  • Request the free bump to 10,000 credits/week

Rules

  • Agents write code. You still own it, and explain it.
  • Your writing is yours — no LLM drafting or polishing
  • Keep the evidence: prompts, diffs, tests, notes
  • No private, restricted, or credential data in any tool
